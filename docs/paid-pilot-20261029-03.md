## Case 1: Wrong Identifier Propagation

Task 121, Structured. Event numbers below are trace `t` values, not file lines.

| Stage | Evidence |
| --- | --- |
| Correct source | Event 32, DataAnalyst e5: restaurant `Suruchee`, Newark, cost 44 |
| Independent correct arrival | Leader's own tool result event 113, e12, also contains `Suruchee` |
| Sender has correct source | ConstraintAnalyst's tool result event 149, e14 |
| First observed wrong spelling | ConstraintAnalyst assistant event 182; queued message event 184 says `Surachee` |
| Peer propagation | Encoded event 195; DataAnalyst inbox event 196, reasoning event 199 |
| Report to Leader | Queued event 200; encoded m9 event 213, with `Surachee` in a claimed verbatim row citing e5/e6/e16 |
| Decision-time receipt | m9 delivered event 225; included in Leader call event 226; final decision call event 385 |
| Outcome | Final Day 3 lunch `Surachee, Newark` fails native sandbox-entity check |

The wrong value first appears in sender message construction, before the pure
encoder. Later reports repeat it as verified. Cited identifiers exist, but the
claimed row is not supported by their text. Thus docid presence would miss the
problem. Correct evidence also reached the Leader independently: this is **not**
a case where the correct fact never arrived. Record edge distortion, unsupported
quotation and conflict-resolution failure separately from end-to-end availability.

Unpaid grader-only intervention: changing only `Surachee` to `Suruchee` in the
final artifact changes native and supplemental grade from fail to pass. Reported
cost changes from 942 to 1,030 because the unrecognized meal was not costed.
This establishes the artifact's scoring defect, NOT that changing a communication
policy would make the LLM choose correctly. Original result remains incorrect.

## Case 2: Scorer Scope and Available Evidence

Task 120, Document Retrieval. Native `valid_cuisine` rejects the American-cuisine
constraint. The final includes American food in Asheville (origin), but the
scorer only counts meals outside the origin. The public rules in this batch did
not explicitly state that exclusion. This is a task/scorer specification gap,
not clean evidence for the motivation's "sufficient initial information" premise.

DataAnalyst e4 (event 40) contains Minneapolis American alternatives. Messages m5
(event 176) and m8 (235) recommend Elite Indian Restaurant, Minneapolis, cost 89.
Leader independently reads the destination rows at event 201, e27. Facts were
available through both reports and direct search, not simply unshared/unread.

Unpaid grader-only intervention: replace Day 2 lunch with the already recommended
Elite Indian Restaurant. Native and supplemental grade become pass; total cost
changes from 1,943 to 2,153, still within budget. Original result remains incorrect.

The shared public contract now explains the origin exclusion **after** this
batch. It has offline coverage only and must use a new manifest/output directory
for any future paid run. No original task, trace, grade or aggregate was rewritten.

Do not remove censoring by scoring drafts as finals or increasing only one arm's

## Feedback and Research Implications

Use decision-relevant fact/qualifier instances, with separate dimensions:
source correctness; source-to-intent fidelity; intent-to-handoff fidelity;
delivery and model-input receipt; source support of quotations; all-path
availability; reconciliation/action; task/scorer adequacy; resource termination.
Keep causal effect `not_tested` until an authorized controlled model intervention.

The two failed outcomes above were manually reviewed by the coding assistant;
independent human or judge agreement remains unmeasured. Automatic review
packets keep semantic labels unknown. Exact-excerpt checks only prioritize
review: formatting/paraphrase can also cause a substring mismatch, while a
matching quote does not prove the associated claim or its relevance.

Evidence supports a need for information-level diagnosis and a concrete
misinformation-propagation case. It does **not yet establish** pure
non-sharing/non-reading as a causal bottleneck, a benefit from RSI, or a superior
handoff form. Short TravelPlanner remains a diagnostic candidate, not an
approved sole main benchmark: Summary passed all six and one error involves
unpublished evaluator scope. This pilot covers constraint-heavy tasks, not all
three proposed task families.
